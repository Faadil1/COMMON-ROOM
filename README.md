# COMMON ROOM

**Day 17 — North Quarter Public Library**

COMMON ROOM reimagines the public-library card as a belonging artifact rather than a generic access credential.

## Prototype scope

This repository currently targets the first TRACE runtime checkpoint only:

- Hero — establish belonging, not card redesign
- Discover — `Leave Your Mark` fragment interaction
- Reveal — resolved member record with tactile physical craft
- Collection glimpse — prove the four-card family

Canonical identities: **READER / MAKER / SEEKER / LOCAL**.

## Direction

**THE LIVING COLLECTION** — Cultural Specimen is the dominant visual foundation; the Wildcard contributes only the human-trace / participation mechanic.

> A library card should not just unlock access. It should express belonging.

> Every member becomes part of the collection.
